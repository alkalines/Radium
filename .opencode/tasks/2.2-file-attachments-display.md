# Task 2.2: File Attachments Display

## Phase
Phase 2 - Message Rendering Enhancements

## Priority
High

## Complexity
Medium

## Dependencies
- Phase 1 should be complete

## Goal
Display uploaded files and images within user messages in the conversation, showing thumbnails for images and file icons for other attachments.

## Current State
- `MessageAttachment` and `MessageAttachments` components exist in `src/components/ai-elements/message.tsx`
- File upload functionality works (files are uploaded and sent with messages)
- Files are NOT rendered in the conversation - users can't see what they uploaded
- File parts exist in `message.parts` but are filtered out in rendering

## Files to Modify

### 1. `src/app/chat/[chatID]/page.tsx`
- Filter file parts from message.parts
- Render `MessageAttachments` with `MessageAttachment` for each file
- Display before text content for user messages

## Implementation Details

### Step 1: Import required components
```tsx
import {
  Message,
  MessageContent,
  MessageResponse,
  MessageAttachment,
  MessageAttachments,
} from "@/components/ai-elements/message";
```

### Step 2: Update message rendering in page.tsx

```tsx
{messages.map((message, messageIndex) => {
  // Extract file attachments from message parts
  const fileAttachments = message.parts.filter(
    (part) => part.type === "file"
  );
  
  return (
    <div key={message.id || `msg-${messageIndex}`}>
      {/* Render file attachments before text content */}
      {fileAttachments.length > 0 && (
        <Message from={message.role}>
          <MessageAttachments>
            {fileAttachments.map((attachment, attachmentIndex) => (
              <MessageAttachment
                key={`${message.id}-attachment-${attachmentIndex}`}
                data={attachment}
              />
            ))}
          </MessageAttachments>
        </Message>
      )}
      
      {/* Render other parts (text, reasoning, etc.) */}
      {message.parts.map((part, partIndex) => {
        switch (part.type) {
          case "file":
            // Skip - already rendered above
            return null;
            
          case "text":
            return (
              <Message
                from={message.role}
                key={`${message.id}-${partIndex}`}
              >
                <MessageContent>
                  <MessageResponse>{part.text}</MessageResponse>
                </MessageContent>
              </Message>
            );
            
          case "reasoning":
            // ... existing reasoning handling
            
          default:
            return null;
        }
      })}
    </div>
  );
})}
```

### Alternative: Combined Message Rendering
If you prefer attachments inline with text in the same message bubble:

```tsx
{messages.map((message, messageIndex) => {
  const fileAttachments = message.parts.filter(part => part.type === "file");
  const textParts = message.parts.filter(part => part.type === "text");
  const reasoningParts = message.parts.filter(part => part.type === "reasoning");
  
  return (
    <div key={message.id || `msg-${messageIndex}`}>
      {/* Reasoning parts first */}
      {reasoningParts.map((part, idx) => (
        <Reasoning key={`reasoning-${idx}`} /* ... props */>
          {/* ... */}
        </Reasoning>
      ))}
      
      {/* Combined message with attachments + text */}
      {(fileAttachments.length > 0 || textParts.length > 0) && (
        <Message from={message.role}>
          {/* Attachments at top of message */}
          {fileAttachments.length > 0 && (
            <MessageAttachments>
              {fileAttachments.map((attachment, idx) => (
                <MessageAttachment 
                  key={idx} 
                  data={attachment}
                />
              ))}
            </MessageAttachments>
          )}
          
          {/* Text content */}
          {textParts.map((part, idx) => (
            <MessageContent key={idx}>
              <MessageResponse>{part.text}</MessageResponse>
            </MessageContent>
          ))}
        </Message>
      )}
    </div>
  );
})}
```
