### Step 4: Implement handleRegenerate

```tsx
const handleRegenerate = () => {
  // The regenerate function from useChat handles:
  // 1. Removing the last assistant message
  // 2. Re-sending the last user message
  // 3. Streaming the new response
  regenerate({
    body: {
      model: models?.find((m) => m._id === selectedModel)?.slug,
    },
  });
};
```

### Alternative: Manual regeneration approach

If the built-in `regenerate` doesn't work as expected, you can implement it manually:

```tsx
const handleRegenerate = () => {
  // Find the last user message
  const lastUserMessageIndex = [...messages]
    .reverse()
    .findIndex((m) => m.role === "user");
  
  if (lastUserMessageIndex === -1) return;
  
  const actualIndex = messages.length - 1 - lastUserMessageIndex;
  const lastUserMessage = messages[actualIndex];
  
  // Get the text from the user message
  const userText = lastUserMessage.parts
    .filter((p) => p.type === "text")
    .map((p) => p.text)
    .join("\n");
  
  // Remove messages after (and including) the last assistant message
  // Keep up to and including the last user message
  setMessages(messages.slice(0, actualIndex + 1));
  
  // Re-send the message to get a new response
  sendMessage(
    { text: userText },
    {
      body: {
        model: models?.find((m) => m._id === selectedModel)?.slug,
      },
    }
  );
};
```
