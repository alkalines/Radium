# Radium Rules

## 1. Code Style
Keep you code in the same style as the actual Radium codebase. This includes indentation, naming conventions, and file structure.

## 2. Testing
If you can use a browser tool like chorme-dev-tool-mcp to test your code, please do so. If not, write unit tests to ensure your code works as expected.

## 3. Documentation
Document your code thoroughly. Use comments to explain complex logic and provide examples where necessary. Also, update any relevant documentation files to reflect changes made.

## 4. Searching for documentation
If you have any tool like context7 to search for documentation, please use it to find relevant information before asking for help.
